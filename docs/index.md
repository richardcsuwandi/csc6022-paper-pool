# CSC6022 Paper Pool

A categorized collection of papers for CSC6022 Machine Learning course at [CUHK-Shenzhen](https://www.cuhk.edu.cn/en/home), taught by [Prof. Feng Yin](https://sai.cuhk.edu.cn/en/teacher/97/).

Use the navigation bar (or search) to browse by topic. Each paper links directly to its PDF, which you can view in the browser or download.

## Categories

- **[ML Classics / Optimization for ML](ml-classics-optimization.md)** — foundational optimization methods and classic ML algorithms
- **[Bayesian ML](bayesian-ml.md)** — Bayesian optimization, sparse Bayesian learning, and probabilistic deep learning
- **[Unsupervised Learning / Generative Model](unsupervised-generative.md)** — generative models, diffusion, clustering, and latent variable models
- **[Sequential Data Modeling / State Space Model](sequential-ssm.md)** — state space models, Kalman filtering, and sequence modeling architectures
- **[DL Classics](dl-classics.md)** — landmark deep learning papers in computer vision, NLP, and training techniques
- **[Information Theory / Complexity and Generalization](info-theory-generalization.md)** — generalization theory, complexity measures, and information-theoretic foundations
- **[Modern Topics (LLMs / Agents / World Models)](modern-topics.md)** — large language models, agents, world models, and other modern topics
