# CSC6022 Paper Pool

A categorized collection of papers for CSC6022, published as a browsable/searchable site with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

Live site: https://richardcsuwandi.github.io/csc6022-paper-pool/

## Categories

- ML Classics / Optimization for ML
- Bayesian ML
- Unsupervised Learning / Generative Model
- Sequential Data Modeling / State Space Model
- DL Classics
- Information Theory / Complexity and Generalization

## Local development

```bash
pip install -r requirements.txt
mkdocs serve
```

## Contributing

See [docs/contributing.md](docs/contributing.md) — TAs and instructors can add papers directly by dropping a PDF into the right category folder and adding one line to that category's page.
